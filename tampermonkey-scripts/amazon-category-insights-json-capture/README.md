# Amazon 类目洞察数据采集器 · 6.7.0

用于美国 Seller Central 类目洞察页面，采集类目表现、畅销 ASIN、新发布 ASIN、产品特征趋势，导出原始 JSON ZIP。

## 安装与更新

在 Tampermonkey 中安装 `amazon-category-insights-json-capture.user.js`；旧 v6.6 用户可在原脚本编辑器中完整替换、保存并刷新页面。显示名称改为稳定中文名称，请检查只启用一份 JSON 采集器。

固定平台地址：`https://tools.aioz.cc/tampermonkey-scripts/amazon-category-insights-json-capture/amazon-category-insights-json-capture.user.js`。两个更新元数据均指向此地址，后续由 Tampermonkey 按用户设置检查更新。首次从无更新地址的旧脚本迁移需要手动替换。平台尚未发布时，该地址不代表可安装或已验证的线上版本。

fflate 0.8.3 ZIP 依赖已内置，无需从第三方 CDN 等待 JSZip 或 FileSaver。`document-start` 同步安装监听，面板稍后创建；打开页面不会自动遍历目录。

## 操作

1. 打开 `https://sellercentral.amazon.com/selection/category-insights`，选择商店、类别、商品类型和关键词。
2. 第一次安装后刷新页面，或重新切换商品类型，让脚本观察 `getFilters` 关键词目录。请求只携带节点、缺少完整父级代码时，需要这份目录校验，未准备好时数据会隔离。
3. 手动切换节点即可被动采集；需要自动遍历时勾选循环层级，点击“开始自动抓取”。关键词必选，勾选外层会包含内层。默认延迟 5–35 秒，最低 3 秒；每批 50 节点，总数 0 表示不限。
4. 每节点等待四类响应及已观察请求结束，最多 60 秒。超时记录缺失并继续；不是完整成功。父级目录等待最多 25 秒，无法验证时结束本轮遍历。
5. “下载选中”或单节点“下载”导出待下载响应；自动任务达到批量阈值或结束时导出待下载数据。
6. 下载后才返回的有效响应显示为“补充”，再次下载会输出独立补充 ZIP，元数据 `supplement_of` 指向先前批次。
7. “下载隔离包”保存归属不明、冲突、无效响应及归属证据；不得把这些文件当作已归类数据导入。
8. “补采当前节点”创建新轮次并点击当前关键词。页面未重新请求时，请手动切换其他关键词再切回。新轮次保留旧轮次；旧轮次迟到响应不能覆盖新轮次。
9. “历史补下载”从 IndexedDB 读取所有历史记录。列表“隐藏”不删除本地数据。下载只代表触发，需检查浏览器下载记录。

自动遍历时手动切换筛选器会终止自动任务并保留结果。请勿同时启动 Mapper 的自动遍历；请求限流、登录失效等会写入异常记录，本脚本不主动重放 dashboard 请求。

## 归属与文件格式

- 请求发出时固定节点证据、父级路径和采集轮次。只使用明确的请求字段、已验证父级目录及已知指标容器，不使用响应到达时的页面节点、不从任意数字或商品标题猜归属。
- 请求字段适配 `nodeId` / `browseNode` / `browseNodeId` / `bnId`、marketplace、`catId` / `categoryId`、`ptdId` / `productTypeId` 等明确字段，以及 `filter.filters`。未识别的真实结构会隔离，需根据脱敏后的请求证据扩展适配器，不能保证所有 Amazon 接口变体均被覆盖。
- 请求、响应明确节点或父级代码冲突时隔离；同轮次同类型以请求发出顺序保留较新的有效结果。
- 保留 `节点ID_文件数/节点ID丨响应类型丨时间戳.json` 和 `NODE丨节点ID丨时间戳.json`。原始业务响应正文不改写。
- NODE 元数据沿用 schema_version 1 及原字段，新增完整路径、轮次、导出批次、请求证据、缺失类型和补充包关联；ZIP 根部增加 `采集报告.json`。
- 相同节点 ID 出现在不同父级或不同轮次时，分成不同 ZIP，避免同目录混淆。单批中可能有部分完整、部分缺失节点，查看报告。
- 本地数据位于当前站点 IndexedDB `amz_category_insights_capture_v1`，包含业务响应，存储随采集增长。刷新会保留已存响应，刷新前未结束的请求按缺失处理，不可能跨页面继续接收。
- 存储失败时停止自动遍历，保留内存中尚未持久化的数据；不要立即刷新，可尝试下载。脚本不保存 Cookie、Authorization 或完整请求头，不上传额外遥测。

## 验证边界

本地回归采用合成目录、请求和响应，在隔离浏览器页面执行。未访问真实 Amazon 登录账户；真实 DOM、请求变体、Tampermonkey 注入环境和线上更新需实站验证。只匹配美国 `.amazon.com`，不自动扩展其他国家域名。
