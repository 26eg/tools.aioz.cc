    脱敏规则

    1. 选择工作簿，自动扫描所有列。
    2. 核对类型与策略，调整需保留的文本列。
    3. 生成 ZIP，内含脱敏工作簿与字典。
    人名统一编码
    销售员、销售员*、IPD、GTM 共用字典；同一完整人名只对应一个编码。
    店铺保留后缀
    按完整名称去重后保留末尾 3 个 Unicode 字符；不足 3 字保留完整原值。
    其他列独立编码
    各列独立去重。不同列编码不重复，人名共用映射除外。
    日期与小数
    仅转换明确日期；日期列不脱敏。数值按底层值四舍五入至 2 位，包括负数与比例值。
    真空白
    空字符串、纯空格和不可见空白字符清为真空白；0、false、NULL、N/A 不当作空白。
    1. 选择需恢复的工作簿。
    2. 选择同一次导出的字典。
    3. 校验映射并导出已解密 XLSX。

    恢复名称和工作表名。已清洗的日期、两位小数和真空白保持不变。

    支持数据行排序与筛选后的子集；保留首行表头与完整编码。混用其他批次或编码残缺会停止处理。

    处理正文、常规属性、内嵌 JSON 和 JavaScript 字符串；保留报告结构。工具不会打开或执行报告。

    图片里的文字、外部文件、压缩/编码数据、跨标签拆开的编码，以及 CSS 或 URL 中的编码需要先转换为普通文本。

    字典等同于恢复钥匙

    字典含原始明文。对外共享时只发送脱敏工作簿，不要发送整个 ZIP。店铺后 3 字符和同值关系仍会保留。

    文件兼容范围

    处理所有工作表，含隐藏行列与隐藏表；表名替换为“工作表1…”并可恢复。保留列宽、行高、冻结窗格、筛选和常规单元格格式。

    表头统一在第 1 行。每文件 ≤ 30 MB、解压后 ≤ 100 MB、已存储单元格 ≤ 500,000。复杂对象、公式、合并、超链接、验证、条件格式和保护表暂不支持，先导出为值表。

    共享字符串缓存、作者属性、人员信息、页眉页脚和自定义名称会清理。富文本恢复为普通文本。文件名与表头保持原样，分享前自行检查其中是否有敏感信息。

    自动识别不会理解所有业务含义。仅由数字组成的账号应在源文件中设为文本；前导零标识和长数字文本默认按文本处理。
