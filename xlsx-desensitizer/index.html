人名统一编码

店铺保留后缀
批次编码为 S1+原末尾3字，完整原值去重，并保留末尾 3 个字符。
其他列友好短编码
批次编码为 X1、X2…；相同语义字段内相同原值一致，跨字段不混用，并避开本批原始文本。
日期与小数
仅转换明确日期；日期列不脱敏。数值按底层值四舍五入至 2 位，包括负数与比例值。

字典等同于恢复钥匙

字典含原始明文。对外共享时只发送脱敏工作簿，不要发送整个 ZIP。店铺后 3 字符和同值关系仍会保留。

文件兼容范围

逐文件选择工作表，输出仅保留所选表；表名替换为“工作表1、工作表2…”并可恢复。保留列宽、行高、冻结窗格、筛选和常规单元格格式。

表头统一在第 1 行。每批 ≤ 30 文件、输入合计 ≤ 150 MiB、字典 ≤ 100,000 映射、结果合计 ≤ 150 MiB；每文件 ≤ 50 MiB、解压后 ≤ 250 MB、已存储单元格 ≤ 2,000,000。复杂对象、公式、合并、超链接、验证、条件格式和保护表暂不支持，先导出为值表。不支持的部件会明确拒绝；可安全处理的辅助部件按既有规则清理。

共享字符串缓存、作者属性、人员信息、页眉页脚和自定义名称会清理。富文本恢复为普通文本。文件名与表头保持原样，分享前自行检查其中是否有敏感信息。

自动识别不会理解所有业务含义。仅由数字组成的账号应在源文件中设为文本；前导零标识和长数字文本默认按文本处理。
