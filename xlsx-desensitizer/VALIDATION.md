## 已确认的业务规则

- 文本日期仅在明确、合法时转成 Excel 真实日期；歧义日期保持原样并提示。
- 日期列不脱敏。工作簿恢复仅还原名称和表名；已舍入数值、真实日期、真空白不回退。
- 全部销售员前缀字段及 IPD/GTM 共用人名映射；其他列独立。店铺完整值去重并保留末尾 3 个字符。

## 测试覆盖与边界

测试包含：全列晚出现的文本异常、正负半值舍入、1900/1904 日期系统、闰年、歧义和无效日期、Excel 原生 ISO 日期与错误类型、百分比格式、前导零和长数字文本、假空白、不同列同值、多人列共用、店铺相同后缀与短名称、Unicode 字符、跨表及隐藏表、恢复排序子集、重复脱敏、字典误配/篡改、残缺编码、Excel 转义与换行、HTML 特殊字符、JSON 大数精度、JS 字符串、非法脚本、CSS/URL 等不支持位置，以及 ZIP 大小、CRC 与 XML 实体检查。

本次没有人工打开 Windows Excel / macOS Excel，也没有用户提供的真实 HTML 报告。报告功能使用带正文、属性、JSON 和 JS 字符串的合成报告，含特殊字符与大数边界，并在隔离浏览器里验证了测试报告的脚本数据。复杂 Excel 对象会明确拒绝，不宣称原样支持。大工作簿受页面列明的体积/单元格数限制；如生成字典或输出超过可读回范围，则停止并要求拆分。

测试命令和兼容规则见根目录 README。构建输出在 `dist/` 中，修改源代码后需同时更新浏览器包。
