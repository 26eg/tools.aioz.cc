# 工作簿脱敏与恢复验收

## 运行检查

- `npm run typecheck` 检查 TypeScript 类型。
- `npm test` 使用合成数据检查单文件、多文件、字段关联、字典兼容、报告解密与不支持的结构。
- `npm run build` 生成浏览器及 Worker 资源。发布前检查浏览器控制台、资源响应与 CSP。

## 浏览器与数据核验

- 检查映射组矩阵、按表查看、键盘操作、字段关联、批量移组和固定操作栏。修改配置、取消或清空后，旧下载应失效。
- 检查普通日期及越界占位值、旧字典续批、同前缀店铺编码、全角表头与保留字段。比较恢复数据、样式、列宽、行高、冻结窗格及原始文件哈希。
- 使用合成或本地授权数据验证不支持的公式与外部链接被明确拒绝。不同来源、版本及结构的样本应单独记录结果。
- 页面加载后验证离线脱敏、批量恢复和报告解密，观察网络请求和控制台错误。
- 私有样本入口和复跑命令见仓库 README。原始数据、恢复字典、详细报告及截图由操作者留在本地。
